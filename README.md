# jestUsingTS
This is practice code to learn working with JEST using TypeScript for testing Back-End APIs 

> this is a practice purpose repo could have incomplete components

## Install
```
git clone https://github.com/pritesh-git/jestUsingTS.git
cd jestUsingTS
npm i or yarn
```

### Run on terminal
```
npm run test
or 
yarn run test
```
